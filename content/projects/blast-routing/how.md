Six modules turn a scene description into a route and exchange only files, so any stage can be resumed or replaced. A fast physical model gives a prior danger map in seconds; a Gaussian process corrects it with the few ARMEN runs the acquisition loop asks for; a graph search then extracts the route. One input, the time you can afford, sets the number of simulations N: N = 0 answers in under a minute, N = 20 takes about a day in 3D.
