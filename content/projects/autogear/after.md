- **The plan.** The last prototype was modified to record rides, so that the model would learn from our own shifting: the hardware would provide the data, the data would train the model, and the model would run on the hardware.
- **June 2026: end of the team project.** Lack of time and bad weather meant the recording campaign was not run. The project closed with the hardware and a proof-of-concept model, a two-stage shift classifier judged offline.
- **Summer to October 2026: the extension.** The prototype was no longer available, so I rebuilt the closest public equivalent of its data and judged every policy in closed-loop replay. The planned classifier reached 66.0 % within one gear of the rider; predicting the target gear instead reaches 87.0 %, against 80.8 % for a decision table given the torque, in closed-loop simulation on reconstructed public data.
- **Hardware and model.** The model is compiled for the board's microcontroller and reproduces the Python reference exactly, but it has not run on the bike: the Arduino integration sketch has not been tested. Bringing the two together is the next step.
- **Other models, same target.** A small MLP reaches 86.8 % (2.2 KB), a random forest 85.8 % (31.4 KB), a linear regression 84.8 % (172 B), a learned speed × slope table 82.0 % (289 B). The boosted trees were kept for their consistency (13 wins of 14), their behaviour on short training sets and their simple deployment.
