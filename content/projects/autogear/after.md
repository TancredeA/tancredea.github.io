- **The plan.** The last prototype was modified to record rides, so that the model would learn from our own shifting: the hardware would provide the data, the data would train the model, and the model would run on the hardware.
- **June 2026: the data never came.** Lack of time and bad weather meant the recording campaign was never run. The project ended with the hardware on one side and, on the other, models designed for data that did not exist: a two-stage shift classifier, judged offline.
- **October 2026: the model, without the prototype.** The prototype was no longer available. I rebuilt the closest public equivalent of its data and judged every policy in closed-loop replay: the planned classifier fell short (66.0 % within one gear of the rider), and predicting the target gear instead reaches 87.0 %, against 80.8 % for a decision table given the torque, in closed-loop simulation on reconstructed public data.
- **The two never met.** The model is compiled for the board's microcontroller and reproduces the Python reference exactly, but it has never run on the bike: the Arduino integration sketch has not been tested. Bringing hardware and model together is the first next step.
- **Other models, same target.** A small MLP reaches 86.8 % (2.2 KB), a random forest 85.8 % (31.4 KB), a linear regression 84.8 % (172 B), a learned speed × slope table 82.0 % (289 B). The boosted trees were kept for their consistency (13 wins of 14), their behaviour on short training sets and their simple deployment.
- **The report.** Ten pages in IEEE format, below: the data reconstruction, the protocol, why the first approach falls short, the results and the firmware. The code, the data pipeline and the firmware library will be published on GitHub.
